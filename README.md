# Chimera-L1 Pipeline

Высокопроизводительный биоинформатический конвейер (pipeline) для *in silico* деконволюции химерных чтений eCLIP и статистически достоверного картирования сайтов связывания AGO2/микроРНК на транскриптах ретротранспозонов LINE-1.

## О проекте (What the project does)

**Chimera-L1** представляет собой комплексное решение для анализа взаимодействий между микроРНК (в частности, miR-128-3p и let-7-5p) и транскриптами LINE-1 in vivo[cite: 1, 3]. Пайплайн автоматизирует весь цикл исследования: от обработки сырых геномных аннотаций и FASTQ-файлов до извлечения гибридных биофизических признаков и обучения ML-моделей[cite: 2, 6, 4]. Финальным этапом является строгая статистическая валидация кандидатов с контролем уровня ложных открытий [FDR](cite: 5).

## Ключевые возможности и преимущества (Why the project is useful)

* **Строгая биологическая фильтрация**: Извлечение только полноразмерных, молодых подсемейств L1 (L1HS, L1PA1) из RepeatMasker[cite: 7]. Исключение элементов, читаемых насквозь с генов-хозяев[cite: 2].
* **Эпигенетический скрининг**: Оценка активности промоторов (5'-UTR) на основе данных GRO-seq (nascent транскрипция) и H3K9me3 [гетерохроматин](cite: 2).
* **Продвинутая деконволюция химер**: Использование `ChiRA` для split-mapping и `TElocal` (EM-алгоритм) для точного разрешения мульти-маппинга коротких чтений[cite: 6].
* **Гибридное извлечение признаков (Feature Extraction)**: Вычисление термодинамики дуплексов (ViennaRNA), оценка стерической доступности (конкуренция с hnRNPA1) и генерация 768-мерных эмбеддингов с помощью нейросети RNA-FM [Sliced Wasserstein Embeddings](cite: 3).
* **Предотвращение утечки данных (Data Leakage)**: Балансировка классов и строгое разделение пересекающихся пиков для обучения модели XGBoost без смещения[cite: 1, 4].
* **Надежная статистика**: Использование стратифицированной пространственной кросс-валидации (Spatial Group CV) и двухэтапного адаптивного Монте-Карло тестирования (перестановки динуклеотидов через `uShuffle`) для контроля FDR (Benjamini-Hochberg q-value $\le$ 0.05)[cite: 5].

## Быстрый старт (How users can get started)

### Системные требования

* **ОС**: Linux
* **CPU**: $\ge$ 14 ядер / 28 потоков [Скрипты жестко ограничены 24 потоками для стабильности системы](cite: 3, 4, 5).
* **GPU**: NVIDIA GPU (рекомендуется RTX 3070 или лучше) с поддержкой CUDA для ускорения XGBoost и PyTorch[cite: 4, 5].
* **RAM**: 32 ГБ
* **Менеджер пакетов**: `mamba` (рекомендуется) или `conda`.

### 1. Установка и настройка окружения

Клонируйте репозиторий и создайте необходимую структуру директорий:

```bash
git clone https://github.com/username/chimera-l1-pipeline.git
cd chimera-l1-pipeline

# Инициализация структуры папок для данных и логов
chmod +x setup_directories.sh
./setup_directories.sh

```

Создайте и активируйте виртуальное окружение:

```bash
mamba env create -f environment.yml
mamba activate chimera_pipeline

```

### 2. Подготовка данных и индексов

Разместите сырые данные в папке `data/raw/` (согласно структуре, описанной в `setup_directories.sh`).
Перед запуском пайплайна необходимо собрать геномный индекс для выравнивателя STAR[cite: 6]:

```bash
mkdir -p data/indices/STAR_hg38

STAR --runThreadN 24 \
     --runMode genomeGenerate \
     --genomeDir data/indices/STAR_hg38 \
     --genomeFastaFiles data/raw/genome/hg38.fa \
     --sjdbGTFfile data/raw/genome/gencode.v45.annotation.gtf.gz

```

*Примечание: Также требуется загрузить индекс TElocal (`hg38_rmsk_TE.gtf.locInd.gz`) в папку `data/indices/*`[cite: 6].

### 3. Запуск пайплайна

Используйте мастер-скрипт `main.sh` для оркестрации выполнения. Вы можете запустить пайплайн целиком или пошагово:

```bash
# Выдать права на исполнение
chmod +x main.sh extract_l1_rmsk.sh chimeric_mapping.sh

# Запуск всего пайплайна от начала до конца
./main.sh --all

# Выполнение отдельного этапа
./main.sh --step extract_l1
./main.sh --step epigenetic_filter
./main.sh --step chimeric_mapping
./main.sh --step feature_extraction
./main.sh --step model_training
./main.sh --step statistical_validation

```

Для извлечения нужных ретротранспозонов из аннотации RepeatMasker (`rmsk.txt.gz`) в формат BED6 не требуется писать тяжеловесный скрипт на Python. Идеальный инструмент для потоковой обработки таких текстовых файлов — комбинация Bash и `awk`. Это позволит обработать файл размером в сотни мегабайт за считанные секунды без загрузки его целиком в оперативную память (RAM).

Чтобы ускорить чтение и использовать мощности вашего процессора (Intel Xeon E5-2680 v4), скрипт проверяет наличие многопоточного архиватора `pigz`. Если он есть, распаковка потока будет распараллелена.

Вот готовый, production-ready Bash скрипт `extract_l1_rmsk.sh`, который строго следует вашей биологической методологии (только эволюционно молодые `L1HS` и `L1PA1`, длина $\ge 6000$ bp, только канонические хромосомы).

### Как это использовать в конвейере

Чтобы запустить скрипт с параметрами по умолчанию:

```bash
bash extract_l1_rmsk.sh

```

Чтобы передать собственные пути (в случае, если главный оркестратор вызывает его):

```bash
bash extract_l1_rmsk.sh \
  --input /path/to/hg38/rmsk.txt.gz \
  --output /path/to/prepped/L1_filtered.bed \
  --min-length 6000

```

Этот скрипт идеально подготовит данные, которые затем съест написанный нами `epigenetic_filter.py`. Если у вас есть черновик следующего этапа (Деконволюция и EM-маппинг химерных eCLIP ридов), отправляйте, и мы продолжим собирать пайплайн!
